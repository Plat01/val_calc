# Калькулятор расчёта стоимости

Одностраничный калькулятор (`index.html`), без сборки и зависимостей —
достаточно открыть файл в браузере. Воспроизводит логику калькулятора
с сайта [формыабс.рф](https://формыабс.рф/katalog/rasschitat-stoimost.html)
в собственном тёмном оформлении. Исходная HTML-страница с оригинальной
разметкой и JS-логикой калькуляторов сохранена для справки в
[reference/original-page.html](reference/original-page.html).

Пересчёт происходит на клиенте при любом изменении полей (`input`/`change`),
без отправки данных на сервер.

## Логика расчёта

### 1. Мастер-модели для вакуумно-формовочных станков

Вход: длина, ширина и высота изделия в мм.

Модель представляется как прямоугольный короб. Считается площадь его
развёртки (дно + 4 боковые стенки):

```
S = Длина × Ширина
  + Длина × Высота × 2
  + Ширина × Высота × 2      // мм²

Цена = S × 0.05              // руб.
```

Константа `MOLD_PRICE_PER_MM2 = 0.05` — цена за квадратный миллиметр
развёртки. Ограничений на ввод (min/max) нет.

### 2. Лист АБС-пластика

Вход: длина и ширина листа в мм, толщина в мм.

Считается объём листа, переведённый в литры, умноженный на цену
за литр материала с наценкой на технологический запас:

```
Цена = (Длина / 1000) × (Ширина / 1000) × Толщина × 1.05 × 450   // руб.
```

Константы:
- `ABS_PRICE_PER_LITRE = 450` — цена за литр материала, руб.
- `ABS_WASTE_FACTOR = 1.05` — +5% на технологический запас.

Ограничения полей:
- Длина: 1–10000 мм
- Ширина: 1–1300 мм
- Толщина: 1.5–4 мм, шаг 0.1

При выходе значения за границы поле автоматически поджимается к
ближайшему допустимому (`min`/`max`), а рядом на 3 секунды показывается
подсказка вида «Минимальное/Максимальное значение: …».

## Изменение цен

Все коэффициенты вынесены в константы в начале `<script>` в `index.html`:

```js
var MOLD_PRICE_PER_MM2 = 0.05;
var ABS_PRICE_PER_LITRE = 450;
var ABS_WASTE_FACTOR = 1.05;
```

Чтобы поменять цену — правится только это место.

## Важно

Расчёт выполняется полностью на клиенте: формулы и коэффициенты видны
любому посетителю через исходный код страницы и могут быть изменены им
в браузере (например, через DevTools) — на итоговую цену, которую видит
только сам посетитель, это не влияет на сервер и не является угрозой
для владельца сайта, но если цена должна быть скрытой или юридически
значимой, расчёт нужно перенести на сервер.
